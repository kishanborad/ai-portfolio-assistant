My strongest skill is bridging the gap between QA and development. I can design a test strategy, implement the automation, set up the CI pipeline, and build the dashboard — end to end. That range means I don't get stuck waiting for someone else to unblock the next step.

I'm good at building tools from scratch when existing solutions don't fit. The test runner playground, the event-stream visualizer, the visual regression engine — none of these use a prebuilt framework. I wrote the execution engines, the rendering logic, and the Python processing pipelines myself.

I'm a fast learner who picks up new tools by building with them. When I needed to understand WebGPU, I built an AI assistant that runs a language model entirely in the browser. When I wanted to understand Kafka internals, I built a playground that simulates the full partition lifecycle.

I care about the details that make software feel polished — smooth animations, clear error states, fast load times. My portfolio playgrounds aren't homework assignments; they're designed to feel like real products.
