I'm Kishan Borad, a QA Engineer and Developer based in the US. I build test automation infrastructure and interactive developer tools. My portfolio site at kishanborad.com showcases my work across both software development and quality assurance.

What drives me is the intersection of testing and development. I don't think of QA and dev as separate disciplines — I write production-quality code that makes testing better, and I bring a tester's eye for edge cases into everything I build.

Outside of work, I enjoy building side projects that explore new technologies. Each playground in my portfolio started as a "what if I could..." experiment. What if I could run Playwright in the browser? What if I could visualize Kafka partitions in real time? What if I could do pixel-level image comparison using Python running in WebAssembly?

I'm drawn to problems where the solution involves making something complex feel simple and interactive.
