The sentiment analysis system combines a Morphological Sentence Pattern (MSP) model with a convolutional neural network. The idea is that systematically researching opinions yields information that is valuable to companies, and combining sentiment analysis with the MSP model obtains better results, with the MSP output improving performance. It is not one of the six projects featured on my portfolio site.

It has a FastAPI backend using TensorFlow and NLTK, and a Next.js frontend. It supports batch processing, part-of-speech tagging, and Swagger API docs. Deployment docs cover Vercel.

It is my oldest public repo, from June 2025, and by far the largest at about 35 MB. It is an ML/NLP project rather than a QA or delivery tool, and it has no verified live demo link.
