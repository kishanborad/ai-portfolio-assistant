Kanha is a desktop-style AI assistant web app, titled ZARVIS, with a boot sequence, desktop, window manager, dock, and app registry. It is an AI assistant presented as a working desktop operating system in the browser. It is not one of the six projects featured on my portfolio site.

Kanha integrates 7 LLM providers: Anthropic, Google, Groq, HuggingFace, Ollama, OpenAI, and OpenRouter. It has voice services, a search service, conversation and memory stores, and a small proxy backend with chat, search, models, and health routes.

The repo metadata links a Vercel deployment. I have not verified that the demo link loads, so if it fails, the repo has the setup for running it yourself.
