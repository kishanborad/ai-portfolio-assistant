I have 4 years of JavaScript/TypeScript experience. Playwright with TypeScript is my primary automation stack. At Prudential I built and maintained the Playwright/TypeScript test infrastructure for advisor dashboards, using layered Page Object Model abstractions with custom fixtures for authentication, test data, and API state, with parallel execution in Docker containers. I also built two browser playgrounds around Playwright: one that generates tests and one that runs them live.
