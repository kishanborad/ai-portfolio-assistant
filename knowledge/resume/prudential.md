What was my role at Prudential? From July 2025 to August 2026 I was a Software Engineer in Test at Prudential Financial, where I built and maintained the Playwright/TypeScript test infrastructure for advisor dashboards managing annuity policies. The framework used layered Page Object Model abstractions with custom fixtures for authentication, test data, and API state. Regression coverage was around 85%.

I wrote Python scripts to generate and seed test data for advisor scenarios, and SQL queries against account and policy databases to validate downstream state. I also wrote API tests for the REST and GraphQL services behind retirement projections, with contract checks that catch schema drift before release. I cut CI/CD execution time by parallelizing runs in Docker containers and managed AWS-based test environments.

I introduced shift-left practices on a 12-engineer squad and mentored 3 junior QA engineers, using AI coding tools like Claude and GitHub Copilot for test-case drafting and data generation. I was not a formal leader or manager; the mentoring was done through code reviews, pair-testing, and shift-left practices alongside my individual contributor work.
