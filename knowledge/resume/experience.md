I've been in QA automation and software development for about five years across four companies, from ed-tech startups to a regulatory compliance lab to Fortune 500 financial services.

Right now I'm a Software Engineer in Test at Prudential Financial, where I build and maintain the Playwright/TypeScript test infrastructure for advisor dashboards managing annuity policies. The framework uses layered Page Object Model abstractions with custom fixtures for authentication, test data, and API state. Regression coverage is around 85%. I write Python scripts to generate and seed test data for advisor scenarios, and SQL queries against account and policy databases to validate downstream state. I also write API tests for the REST and GraphQL services behind retirement projections, with contract checks that catch schema drift before release. I cut CI/CD execution time by parallelizing runs in Docker containers and manage AWS-based test environments. I introduced shift-left practices on a 12-engineer squad and mentor 3 junior QA engineers, using AI coding tools like Claude and GitHub Copilot for test-case drafting and data generation.

Before Prudential, I was a QA & Automation Engineer at UL Solutions, where I built Python and SQL automation pipelines for regulatory compliance data workflows. That replaced roughly 50 hours a week of manual processing. I also automated SAR wireless certification testing across about 50 devices per week and built reporting tooling that cut audit report turnaround from 3 days to about 4 hours.

At iSchoolConnect I was a Product Quality Specialist II from December 2019 to August 2022. I built the Selenium and Cypress automation framework on Page Object Model with Postman API regression suites, moving releases from bi-weekly to weekly. I ran functional and API tests on two AI/ML admissions tools: an Essay/SOP grader that assessed confidence, structure, plagiarism, and grammar, and a video interview analyzer that evaluated behavioral traits, confidence scores, facial expressions, and signs of cheating. I ran JMeter load tests simulating 10,000+ concurrent users, and the fixes from those tests cut page load times about 35%. I coordinated a 6-person QA team on a platform serving 500K+ students.

I started at Quantiphi as an intern and moved to full-time Quality Analyst, scaling their Selenium WebDriver suite from zero to 120+ test cases across 4 product lines, cutting manual regression cycle time by 40%. I also executed functional, unit, and cross-browser testing across Chrome, Firefox, IE, and Opera, remediating 80+ pre-launch UI defects.
