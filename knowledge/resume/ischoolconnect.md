My role at iSchoolConnect was Product Quality Specialist II, from December 2019 to August 2022. I built the Selenium and Cypress automation framework on Page Object Model with Postman API regression suites, moving releases from bi-weekly to weekly.

I tested two AI tools used in admissions: an Essay/SOP grader that assessed confidence, structure, plagiarism, and grammar, and a video interview analyzer that evaluated behavioral traits, confidence scores, facial expressions, and signs of cheating. I ran functional and API tests on both tools, which used machine learning models.

I ran JMeter load tests simulating 10,000+ concurrent users, and the fixes from those tests cut page load times about 35% under peak traffic.
