My primary languages are Python, SQL, and TypeScript. Python handles test automation, data processing, build scripts, and CLI tools. SQL is for data validation against production and test databases. TypeScript covers the frontend: React components, Playwright test suites, and Node-based tooling.

Test automation and frameworks: Playwright with custom fixtures and parallel execution, Selenium WebDriver, Cypress, REST Assured, Postman, JMeter for load testing, TestNG, and JUnit. I've built custom test runners, assertion libraries, and report generators when off-the-shelf tools didn't fit.

Infrastructure and DevOps: AWS (EC2, CloudWatch), Docker, docker-compose, Jenkins, GitHub Actions, Git/GitHub. I write Dockerfiles for reproducible test environments and CI workflows that run matrix builds.

Reporting and practices: Allure, Playwright HTML reports, layered Page Object Model design, API contract testing, shift-left/TDD, AI-assisted test development with Claude and GitHub Copilot, Agile/Scrum, Jira.

Frontend: React, Tailwind CSS, Vite, Canvas API, WebAssembly (Pyodide, DuckDB-WASM). I've built interactive demos that run Python in the browser via Pyodide and SQL engines via DuckDB-WASM.
