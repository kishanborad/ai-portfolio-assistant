My primary languages are Python and TypeScript. I write Python for test automation, data processing, build scripts, and CLI tools. TypeScript is my go-to for frontend work, React components, and Node-based tooling.

On the testing side, my toolkit includes Playwright, Selenium WebDriver, pytest, Vitest, axe-core for accessibility auditing, and PIL/Pillow for visual regression. I've built custom test runners, assertion libraries, and report generators from scratch when off-the-shelf tools didn't fit.

For infrastructure, I work with Docker, Docker Compose, GitHub Actions, and shell scripting. I write Dockerfiles for reproducible test environments and CI workflows that run matrix builds across Python and Node versions.

Frontend: React, Tailwind CSS, Vite, Canvas API, WebAssembly (Pyodide integration). I've built interactive demos that run Python in the browser via Pyodide and render results on HTML Canvas.

Data and APIs: REST API testing with requests and httpx, JSON Schema validation, OpenAPI spec parsing. I've also worked with Kafka-style event streams and built tooling around event production, consumption, and lag monitoring.

Other tools I use regularly: Git, Linux shell, jq, ruff (Python linter), ESLint, Prettier, and various browser DevTools for debugging.
